## What is Python?
Python is a simple and easy to understand language which feels like reading simple English.  
This pseudo-code nature of Python makes it easy to learn and understandable by beginners.  

**Note:** Python is a case-sensitive language.

## Use of Comments

- Single line comment
- Multi line comment
